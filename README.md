# Rexilandia

Juego infantil para colorear dinosaurios, animales y objetos, con voces, música y retos.

## Cómo abrirlo en el ordenador

1. Instala [Node.js](https://nodejs.org) (versión 22).
2. En esta carpeta:

```bash
npm install
npm run dev
```

3. Abre la dirección que salga en la terminal.

El progreso del niño se guarda en el navegador.
